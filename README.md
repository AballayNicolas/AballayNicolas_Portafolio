# Portfolio — Nicolás Aballay

Portfolio estático en HTML y CSS, responsive y sin dependencias de compilación.

## Cómo verlo localmente
Abrí `index.html` en un navegador.

## Cómo publicarlo gratis con GitHub Pages
1. Creá un repositorio público llamado `AballayNicolas.github.io` (o elegí otro nombre).
2. Subí `index.html`, `styles.css` y este README a la raíz.
3. En GitHub, entrá a Settings → Pages.
4. En Build and deployment, elegí Deploy from a branch, seleccioná `main` y `/root`.
5. Guardá y esperá a que GitHub Pages publique el sitio.

## Antes de publicarlo
- Confirmá que los enlaces de proyectos sean correctos y que los repositorios estén presentables.
- Agregá capturas reales de los dashboards cuando corresponda.
- Revisá que la descripción de cada proyecto refleje exactamente tu contribución.
- No publiques datos privados, credenciales ni archivos con información sensible.
